区域预设标注器

把一张牌桌截图框成三块区域，导出可直接喂给应用的预设 JSON。 图片只在这个页面里读，不会上传到任何地方（本页没有任何网络请求）。

把截图拖到这里，或
支持 PNG / JPG。建议用整局开始时的画面，牌点、张数、出牌区都在。
手牌区（你的手牌点数） 张数区（三家剩余张数） 出牌区（桌面出的牌）
怎么用
  1. 选一块区域（默认手牌区），在图上拖出一个框。
  2. 依次框完三块，可随时撤销或重画。
  3. 点「生成预设 JSON」，复制或下载。
  4. 在应用里导入模板，一定要跑一次「试识别」再开局。
快捷键：123 切换区域，Ctrl+Z 撤销，Esc 取消当前框。
