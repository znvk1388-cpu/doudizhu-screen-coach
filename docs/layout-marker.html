牌桌区域标注器

按座位分别框选，生成安卓 0.6.16 可导入的区域模板。图片只在本机浏览器处理，不上传。请用实际共享给应用的完整画面；导入后仍须试识别。

也可拖入图片。框牌点和各家余牌数字，避开顶部记牌器。

先在“标注区域”选择座位，再拖出矩形；手机也能依次点两个对角。坐标输入可代替拖动。1–8 切换必选区域，Ctrl+Z 撤销，Esc 取消当前框。

不确定时保持关闭；不同厂商规则需要在应用里核对。

用坐标标注（百分比，0–100）

  1. 在安卓应用中打开“更多识牌设置 → 备份／导入区域模板”。
  2. 从文件导入，填写新名称另存；不会覆盖当前牌桌。
  3. 切换到新模板并重新校准、试识别。2v2 先手在新局单独确认。
