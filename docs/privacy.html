隐私与本地数据说明

版本 v1.2 · 更新日期 2026-11-14 · 对应安卓 0.6.17 轻量版 / 完整版

维护者：GitHub @znvk1388-cpu。联系：项目 Issues。请勿在公开反馈中上传朋友声音、完整声纹或其他私人内容。

先了解当前版本

  • APK 未声明 INTERNET 权限，没有应用账号或云同步；屏幕识别与内置语音模型在本机处理。
  • 屏幕帧与原始麦克风音频仅用于内存处理，本应用不将其保存为录屏或录音。牌局结果、设置、模板和已注册声纹向量可能保存在本机。
  • 主动导出、分享的文件，以及系统文字转语音引擎，是独立于本应用网络权限的处理路径，具体行为由你选择的接收应用和系统引擎决定。

处理的信息与保存方式

功能信息与用途保存方式
屏幕识牌你主动共享的游戏画面，用于读取牌点与余牌数字。帧在内存中处理；不保存截图。识别文本、确认事件等可进入本机牌局记录。
牌局和模板出牌事件、余量、区域坐标和玩法设置，用于显示、复盘和下次校准。应用私有数据；保留到你删除相应记录、清除应用数据或卸载。没有统一“本机数据”管理页。
中文播报将记牌提示文本交给系统 TTS 朗读。本应用不保存合成音频。系统语音引擎可有自己的联网和缓存设置，建议选择中文离线语音。
现场听牌（仅完整版）麦克风音频用于识别报牌；注册后的声音特征向量用于区分座位。不保存原始录音；向量保存在应用私有 SharedPreferences 中。当前未额外实现 Keystore 加密或到期自动清理。
诊断导出识牌文本、置信度、事件、耗时和设备/系统信息，用于你主动排障。手动触发时在应用私有目录生成或更新文本 JSON，再打开系统分享选择器；取消分享不会自动删除已生成的私有文件；不含截图或原始音频。当前没有导出前内容预览。

权限由你控制

  • 开始识屏需要 Android 系统屏幕共享确认；通知用于展示运行状态，浮窗可选。
  • 仅完整版听牌需要麦克风权限。拒绝麦克风不影响屏幕识牌；轻量版不申请麦克风。
  • 不申请无障碍服务、通讯录、电话、短信、位置或全部文件访问权限。
  • 模板导入导出使用系统文件选择器；诊断导出通过系统分享选择器交给你选定的应用。

声纹：当前限制和清理办法

开始前请先告知朋友并取得同意。声纹特征可能涉及个人身份，不能将本应用的识别人判断当作身份认证。

  • 当前没有独立的“同意并开启”说明页或逐人同意确认流程，系统麦克风授权不等于朋友已经同意。
  • 当前没有逐人删除按钮或 30 天自动清理。重新注册会替换对应座位的向量，关闭听牌和切换到轻量版不会自动删除已有向量。
  • 要清除全部向量，可在系统“应用信息 → 存储”中清除应用数据；这也会删除牌局、模板和设置，请先导出模板并保留需要的记录。清除或卸载不能撤销。
  • 应用私有存储不等于另有加密保护。独立告知、逐人删除、自动到期和额外加密仍是待实现项，本说明不将它们当作现有能力。

如何查看、修正和备份

  • 在牌局历史中查看记录，按现有功能补录、更正、撤销和删除记录；没有统一管理全部数据的页面。
  • 模板入口：“更多识牌设置 → 备份／导入区域模板”。模板文件仅包含区域与玩法，不含截图、录音、声纹或牌局记录。
  • 没有完整牌局与声纹的结构化备份恢复。重要记录可另行截图保留；导出文件由你管理，卸载不会删除你已导出或分享出去的副本。
  • 诊断内容可能包含现场牌局文字。分享前可取消，不要默认发给第三方；当前应用内没有内容预览，可先存到自己控制的位置后查看。
  • 撤回权限可在系统设置完成；停止运行不等于删除已保存数据。系统“清除应用数据”会一次清除本机应用私有数据，请先备份。

第三方组件与外部行为

应用使用 ML Kit 本地文字识别、sherpa-onnx / ONNX Runtime 本地语音组件、AndroidX 等，具体版本与许可随安装包提供。本应用未接入广告、应用账号和云同步服务。系统 TTS、文件选择器与分享接收方各有自身设置；你主动访问下载站或 GitHub 也会产生相应网站请求。

Android 配置关闭应用自动备份。即使卸载会移除应用私有数据，导出文件、分享副本和系统其他组件的数据仍需按其设置管理。
