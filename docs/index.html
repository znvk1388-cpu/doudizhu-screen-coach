安卓第一次使用

  1. 安装并检查权限

    按系统提示允许当前浏览器或文件管理器安装应用。打开“使用指南与检查”，核对通知、浮窗和系统中文播报。听牌才需要麦克风。

  2. 选对你要记牌的画面

    点“开始读取游戏画面”。系统如提供单应用共享，请选实际游戏；微信小程序请选择微信所在画面。不要误选记牌器自身。

  3. 横屏校准，逐家核对

    框选手牌点数、各家出牌区和余牌数字。左、右按屏幕位置；顶部游戏自带记牌器不是某一家的余牌数字。校准后对照真实牌面试识别。

  4. 从完整新局开始

    确认玩法与初始手牌；2v2 另选队友和先手。中途接入、换皮肤或窗口变化时先暂停核对，避免连续错记。

  5. 用按钮控制播报

    浮窗点击声音按钮开关播报，长按切换“关键 / 全部”。暂停或换局会清空待播提示。听现场报牌需切到完整版语音入口。

可先用牌桌区域标注器在截图上逐座位框选并下载模板，再到“更多识牌设置 → 备份／导入区域模板”导入。图片不上传；导入后仍需在应用内试识别。

  • 三人经典 / 不洗牌、连炸；单癞子的实体牌与声明牌型需手动核对。

听牌前先了解声纹

完整版可以为座位注册声音特征。开始前请先告知朋友并取得同意；特征用于本机区分说话人，不能当作可靠的身份认证。

当前 0.6.16 没有独立声纹同意页、逐人删除或 30 天自动到期清理。向量保存在应用私有数据中；重新注册会替换对应座位。要清除全部本地数据，可在系统应用设置清除存储，但会同时删除牌局、模板与设置，请先备份模板。

屏幕识牌无需麦克风，系统中文播报与听现场声音是两项功能。详见隐私与本地数据说明 v1.1。

换手机、备份与未来迁移

先备份并验证，最后再考虑卸载旧应用。 当前 0.6.16 更新和轻量/完整版切换使用原签名覆盖安装，无需先卸载。未来若更换签名或包名，将另行公布具体步骤。

  1. 导出模板

    主界面 → 更多识牌设置 → 备份／导入区域模板 → 导出所选模板，确认文件已保存。

  2. 另存需要保留的记录

    模板只含区域和玩法，不含牌局、录音或声纹。重要牌局可先截图；当前没有完整数据备份与恢复，声音需在新设备重新注册。

  3. 保留旧数据，验证新环境

    换手机时先在新手机安装、导入并试识别；未来只有明确支持新旧包并存时才按并存方式迁移。不要假定改签名后能覆盖安装。

  4. 确认后自行决定是否卸载旧版

    核对模板、玩法和需要保留的记录，确认无遗漏再操作。导出文件和主动分享出去的文件不随卸载删除。
