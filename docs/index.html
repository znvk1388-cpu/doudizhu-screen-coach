安装步骤

  1. 允许安装未知来源应用

    系统会提示"出于安全考虑已阻止"。点提示里的"设置"，允许你的浏览器或文件管理器安装应用即可。

  2. 安装并打开，先别急着开局

    进入主界面 →「使用指南与检查」，按提示依次确认：通知、悬浮窗（可选）、中文离线语音（可选）。

  3. 开始识牌，选对应用

    点「开始读取游戏画面」→ 在系统弹窗里选择斗地主游戏（或微信小程序）。如果系统只允许选单个应用，一定要选游戏本身，选错会读不到牌桌。

  4. 切到游戏，横屏停留几秒

    当前版本以横屏牌桌为主。竖屏牌桌的支持还在做，若你的游戏是竖屏，可能识别不准。

  5. 校准区域，然后试识别

    从通知栏或主界面进入校准，依次框选牌点区、张数区、出牌区。校准完一定点"试识别"，确认识别结果与实际牌面一致再开局。

  6. 从"完整新局"开始

    必须从第一手开始记，不能中途接入。中途接入会导致余量对不上。

每次换手机或换皮肤都要重新框选，很麻烦？用区域预设标注器： 拖一张截图进去，框三块区域，导出 JSON 存成模板，下次导入即可——图片只在本地处理，不上传。

完整版的语音与声纹

"听朋友报牌"需要分辨是哪位朋友在说话，因此会提取声纹。声纹属于敏感个人信息，请了解这几点再决定是否使用：

  • 原始录音不保存，只在本机存数学向量，不上传（应用没有网络权限）。
  • 建议 30 天未使用自动删除，并支持逐人删除、一次清空。
  • 你需要先告知朋友并取得对方同意，不要在对方不知情时采集他人声音。
  • 如果你只需要记牌，用轻量版就好，它完全不涉及麦克风。

换正式签名时怎么迁移

顺序不能错：先导出模板，再卸载/装新版，最后导入。 因为签名或包名变更后，新旧版本无法互相读取数据（Android 的安全机制），而本应用不联网也没有云备份，卸载即清除。

  1. 导出区域模板

    主界面 →「区域模板」→「备份／导入区域模板」→ 导出为文件，记住保存位置。

  2. 需要保留的牌局先截图

    牌局记录目前没有结构化导出，重要对局请先截图留档。

  3. 安装新版（可与旧版共存）

    新版会使用新包名，不会覆盖旧版，两者可以同时存在。

  4. 在新版导入模板并重新试识别

    导入后仍需确认识别结果正确，不要直接开局。

  5. 确认无误后再卸载旧版

    旧版将停止更新。

这个应用不做什么

常见能力本应用原因
联网 / 账号 / 云同步没有安装包里没有 INTERNET 权限，数据无法上传
无障碍服务没有不读取其他应用界面结构，不代替你点击
读取游戏内存没有只处理你授权的屏幕画面
自动出牌 / AI 建议没有不介入操作；这类功能也会带来公平性争议
存储权限没有导入导出走系统文件选择器，只碰你亲手选的那个文件
一句实话：技术只读不等于平台许可。游戏是否允许使用第三方辅助工具由平台规则决定， 我们不承诺"不会被封号"，也不承诺"100% 准确"。请仅用于娱乐对局，不要用于任何涉及现金的牌局。
