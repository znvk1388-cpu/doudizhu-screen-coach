# 斗地主记牌器

Windows 和安卓各自独立运行的斗地主记牌工具。本仓库用于保存安装包、版本说明与校验值。

## 安装包

0.6.10 安装包正在准备上传，上传完成后会在本仓库的 [Releases（版本发布）](https://github.com/znvk1388-cpu/doudizhu-screen-coach/releases) 提供。此说明文件本身不代表安装包已备份成功。

- 安卓：下载完整版 APK，在安卓手机上安装。
- Windows：下载 ZIP，完整解压后运行 `DouDizhuCoach.exe`。
- 更新前保留已有配置；安卓沿用原签名，可覆盖安装。
