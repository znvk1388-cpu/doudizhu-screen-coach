## 语音播报

安卓主界面默认「范围：关键」，优先听已确认的炸弹、王、2、剩一两张、出完和核对提示。想听每手出牌可选「全部」。主界面和悬浮窗仍可一键静音。

Windows 按当前玩法区分普通炸弹、王炸、连炸与 2v2 多张炸弹。主界面可一键静音，也可按 Alt+V。

Windows 180 项、安卓完整版 351 项、轻量版 358 项测试通过。安卓目标真机待实测。
