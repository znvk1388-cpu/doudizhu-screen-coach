## 语音播报

电脑主界面、安卓主界面和悬浮窗都有播报按钮。关闭即停声，识牌继续。再次开启从新消息开始。电脑也可按 Alt+V。

播报使用「下家王炸」「上家剩一张」「轮到你，出对六」等短句。长牌组播报牌型和范围。安卓语音报牌页面用于听玩家说话。

Windows 179 项、安卓完整版 349 项、轻量版 356 项测试通过。Windows 已核对离线中文合成和解压启动，安卓已核对签名和权限，目标真机的播报听感待实测。
